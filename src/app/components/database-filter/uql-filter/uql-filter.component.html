Common recipe

Require the same skills in all three slots

Write one requirement for Main, GP1, and GP2, then connect them with and. This guarantees a three-way match.

infolineage white ranks matches by depth; it does not guarantee that every slot matches. Use the explicit three-slot form when all three are required.

Scope decides where UQL looks

Leave the scope out for a lineage-wide total. Add a scope when the exact slot matters.

Speed >= 6
Total Speed across the visible lineage.
Main Speed >= 3
Only the main parent.
GP1 Speed >= 3
Only the left great parent.
GP2 Speed >= 3
Only the right great parent.
GP Speed >= 3
Either great parent may match.

Slots and operatorsTarget a position and control how it matches expand_more
Main
Main or parent slot.
GP1 / Left
Left great parent.
GP2 / Right
Right great parent.
GP / Any GP
Either great parent.
= != > >= < <=
Compare a value, count, or star total.
and / or / not
Require both, allow either, or exclude a condition.
in (...) / not in (...)
Match any listed value, or exclude all listed values.
has / has all (...)
Require one skill or every listed skill.
has any (...)
Require at least one listed skill.

When mixing and with or, use parentheses: (Speed >= 3 or Stamina >= 3) and Wins >= 30.

Skills, characters, and racesReadable names, lists, and star levels expand_more

Type readable names and choose the correct autocomplete result. Quotes and backend IDs are usually unnecessary.

Main has Right-Handed ○
The main parent has this skill at any star level.
White factors in (Skill A > 3, Skill B)
Match either skill; the first also needs more than 3 stars.
Characters in (...)
Any Main, GP1, or GP2 character is in the list.
Race wins has all (...)
The main parent covers every listed race.
Left race wins in (...)
The left great parent covers any listed race.
Support card = ... and limitbreak >= 4
The named support card is at least limit break 4.
Trainer name ilike '%name%'
Case-insensitive text search; % is a wildcard.
Editor tools and rankingAffinity context, owned legacies, and result order expand_more

These directives configure the editor or result order. They are not ordinary filter conditions.

target = Special Week
Set the affinity target.
owned legacy = []
Open your legacy picker for affinity and race comparison.
sort by = Total White stars
Sort by white star total.
sort by = White skills amount
Sort by raw white skill count.
optional white in (...)
Score and rank matching skills.
lineage white in (...)
Rank by lineage-style skill stacking.
priority = 0
Place a scoring group first; higher numbers break later ties.

lightbulbRanking changes which matches appear first. To make a match mandatory, write it as a normal condition.
